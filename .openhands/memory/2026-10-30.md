## Bugs the tests caught (all fixed in source, not in the tests)
1. `roundTo` used `Math.round(v * 10**d) / 10**d` — `1.005` rounded to `1`, not
   `1.01`, because `1.005 * 100 === 100.49999…`. Fixed by shifting through a
   string: `Number(\`${value}e${decimals}\`)`.
2. `flattenScene` collected roots while iterating `Map.values()`, so a child
   listed before its parent in the input array reordered unrelated roots. Fixed
   by iterating the input array for root collection.
3. `formatBytes` rendered `5.0 MB`; now drops a trailing `.0`.

## Design notes worth keeping
- `TimeController` accumulates wall-clock deltas rather than adding a fixed step
  per animation frame, so a dropped frame does not slow playback down.
- `BottomSheet` snapping uses both position and velocity (a fast flick wins over
  the nearest detent) — that is what makes it feel native.
- `WakeLockController` re-acquires on `visibilitychange`; browsers release the
  lock when the page hides, which would otherwise abort a background export.
- `MemoryManager` budgets from `navigator.deviceMemory` and evicts LRU.
- COOP/COEP headers in `vercel.json` exist so `SharedArrayBuffer` is available
  for the multi-threaded FFmpeg core. Export works without them, just slower.
